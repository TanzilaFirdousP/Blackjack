# Blackjack Game (Go)

A simple command-line Blackjack game built using Go.

## Features
- Player vs Dealer gameplay
- Card shuffling and dealing
- Score tracking system
- Basic Blackjack rules

## Concepts Used
- Structs and Interfaces
- Abstraction (using interfaces)
- Polymorphism (common behavior via interfaces)
- Composition (embedding `hand` in player/dealer)
- Game logic and control flow
- Input validation

## How to Run

```bash
go run main.go
```

## Notes
- This was a collaborative project completed as part of a learning task.
- Focus was on implementing game logic and understanding Go fundamentals.
